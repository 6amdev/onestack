### ✨ Features

#### Core Services
- **Parse Server 6.4.0** - Scalable REST & GraphQL API
- **Parse Dashboard** - Visual data management interface  
- **MongoDB 7.0** - Primary database with authentication
- **Redis 7** - High-performance caching & session management
- **Nginx** - Reverse proxy with SSL/TLS support

#### Security & Performance
- 🔒 **Secure by Default** - No exposed databases, auto-generated passwords
- 🌐 **Multi-Domain Support** - Host multiple apps with single backend
- 📱 **Mobile Ready** - Full support for iOS, Android, Flutter
- ⚡ **Auto-Scaling Ready** - Horizontal scaling capability
- 🔄 **Live Queries** - Real-time data synchronization
- 📊 **Built-in Monitoring** - Health checks and metrics

#### Developer Experience
- 🎯 **5-Minute Setup** - From zero to production
- 🔧 **Modular Architecture** - Add/remove services easily
- 📦 **Docker Native** - Consistent environments everywhere
- 🔄 **Hot Reload** - Development with live updates
- 📚 **Extensive Documentation** - Clear guides and examples

### 🚀 Quick Start

#### Prerequisites
- Ubuntu 20.04+ / Debian 11+ / CentOS 8+
- 2GB RAM minimum (4GB recommended)
- 20GB available storage
- Port 80, 443 available

#### Installation

# 1. Clone repository
git clone https://github.com/6amdev/onestack.git
cd onestack

# 2. Run installer
chmod +x install.sh
./install.sh

# 3. Access your services
# API: http://your-server-ip/parse
# Dashboard: http://your-server-ip/dashboard

That's it! Your backend is ready. 🎉

📖 Documentation
Configuration
All configuration is managed through the .env file:
bash# Core Settings
APP_NAME=MyApp
APP_ID=<auto-generated>
MASTER_KEY=<auto-generated>

# Database
MONGO_USER=admin
MONGO_PASS=<auto-generated>

# Security is handled automatically
💻 API Usage
REST API
bash# Create object
curl -X POST \
  -H "X-Parse-Application-Id: YOUR_APP_ID" \
  -H "Content-Type: application/json" \
  -d '{"name":"John","age":30}' \
  http://your-domain.com/parse/classes/User

# Query objects
curl -X GET \
  -H "X-Parse-Application-Id: YOUR_APP_ID" \
  http://your-domain.com/parse/classes/User
Flutter Integration
dartvoid main() async {
  await Parse().initialize(
    'YOUR_APP_ID',
    'https://your-domain.com/parse',
    debug: true
  );
}
JavaScript SDK
javascriptParse.initialize("YOUR_APP_ID");
Parse.serverURL = 'https://your-domain.com/parse';

const User = new Parse.User();
await User.save();

SSL Certificate Setup
bash# Setup SSL with Let's Encrypt
./scripts/setup-ssl.sh
🔒 Security
OneStack implements security best practices:

✅ Network Isolation - Services communicate through internal networks
✅ No Exposed Databases - MongoDB/Redis accessible only internally
✅ Automated SSL - Let's Encrypt integration
✅ Generated Credentials - Strong passwords auto-generated
✅ CORS Configured - Controlled cross-origin access
✅ Rate Limiting - DDoS protection
✅ Regular Updates - Automated security patches

🔧 Advanced Configuration
Adding Custom Services
Create a new service in docker-compose.override.yml:
yamlservices:
  my-service:
    build: ./services/my-service
    networks:
      - internal
    environment:
      - PARSE_URL=http://parse-server:1337/parse
      - APP_ID=${APP_ID}
Scaling
bash# Scale Parse Server instances
docker-compose up -d --scale parse-server=3

🔒 ความปลอดภัย
OneStack ใช้แนวทางปฏิบัติด้านความปลอดภัยที่ดีที่สุด:

✅ แยกเครือข่าย - บริการสื่อสารผ่านเครือข่ายภายใน
✅ ไม่เปิดฐานข้อมูล - MongoDB/Redis เข้าถึงได้เฉพาะภายใน
✅ SSL อัตโนมัติ - รวม Let's Encrypt
✅ สร้างข้อมูลรับรอง - รหัสผ่านที่แข็งแกร่งสร้างอัตโนมัติ
✅ ตั้งค่า CORS - ควบคุมการเข้าถึงข้ามโดเมน
✅ จำกัดอัตรา - ป้องกัน DDoS
✅ อัปเดตสม่ำเสมอ - แพตช์ความปลอดภัยอัตโนมัติ
